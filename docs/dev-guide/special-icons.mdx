## Conventions

- **Gradient stroke**: primary sweep `#38bdf8 → #818cf8` via `<linearGradient>` referenced as `stroke="url(#id)"`; `animated`/`no_animation` toggles the SMIL shimmer.
- **Composed icons**: declared in `src/lib/icons/composed-icons.ts` (base + overlay node tuples + transform), rendered by `DynamicIcon` with an SVG `<mask>` knockout — never a painted background disc.
- **Host-only icons** (`GradientIcon`, `BotIcon`, `LoadingWatermark`, static assets) are NOT vendored to remote bundles — they live in fe-v3.
- **Excluded — third-party marks, not ours**: the AI-vendor glyphs in `components/ai/*Icon.svelte`, `ModelIcon`, `GpuVendorIcon` (us-v3), and the social-brand symbols in `static/icons.svg` are brand assets we inlined for convenience — not Primebrick-authored icons.
